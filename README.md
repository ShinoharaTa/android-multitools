# QS ミニツール (android-multitools)

Galaxy / One UI のクイック設定パネルから、普段は設定アプリを開かないと変更できない項目を
ワンタップで操作するための個人用 Android アプリ。

Play ストア公開は想定していない。自分の端末に APK を直接インストールして使う。

## タイル

| タイル | 動作 | 必要な権限 |
| --- | --- | --- |
| USB デバッグ | タップのたびに `Settings.Global.ADB_ENABLED` を ON/OFF。状態はタイルの Active/Inactive とサブタイトル (`ON` / `OFF`) に出る | `WRITE_SECURE_SETTINGS` (adb から一度だけ付与) |
| 画面タイムアウト | タップのたびに `Settings.System.SCREEN_OFF_TIMEOUT` を 30秒 → 2分 → 10分 → 30分 と巡回。現在値はサブタイトルに出る | `WRITE_SETTINGS` (設定アプリの「システム設定の変更」から許可) |
| アラーム | 時計アプリのアラーム一覧を開く | なし |

権限が足りないタイルはタップするとセットアップ画面へ飛ぶ。落ちない。

## ホーム画面ウィジェット

「次のアラーム」ウィジェット (2×1)。次に鳴るアラームの時刻と、今日 / 明日 / 日付を出す。
タップするとそのアラームを持っている時計アプリのアラーム画面が開く。

`AlarmManager.getNextAlarmClock()` は時計アプリの種類を問わず端末全体の次の 1 件を返すので、
Galaxy 標準の時計アプリでもそのまま動く。権限は要らない。

更新は `ACTION_NEXT_ALARM_CLOCK_CHANGED` を受けて行う。定期更新も常駐もしない。

文字サイズはウィジェットの幅と高さから毎回計算するので、リサイズすると追従する。
高さが足りないときは見出し (68dp 未満) → 日付 (46dp 未満) の順に省いて、時刻だけを残す。

見た目はアプリのセットアップ画面から変えられる。設定はウィジェット全体で 1 つ。

| 項目 | 選択肢 |
| --- | --- |
| 背景テーマ | システムに合わせる / ライト / ダーク / 黒 (有機EL向け) / 透明 (壁紙に重ねる) |
| 枠線の太さ | なし / 細 (1dp) / 中 (2dp) / 太 (3dp) |

「システムに合わせる」だけは色を一切指定せず、`values` と `values-night` の出し分けに任せる。
つまり端末のダークモード切替に自動で追従する。選んだ結果はセットアップ画面の見本にすぐ出て、
置いてあるウィジェットにも即座に反映される。

アラームの**一覧表示と個別の ON/OFF は Android の公開 API では実現できない**。
理由は [docs/DESIGN.md](docs/DESIGN.md) に書いた。

## アプリのショートカット (ウィジェット)

選んだアプリを 1 タップで開くウィジェット。アイコンとラベルは対象アプリのものをそのまま使い、
ウィジェットの大きさに合わせて拡大縮小する。高さが足りないときはラベルを省いてアイコンだけにする。

追加すると設定画面が開き、そこでアプリを選ぶ。置いたあとでもウィジェットを長押しして選び直せる
(`widgetFeatures="reconfigurable"`)。見た目 (背景テーマ / 枠線) はショートカットごとに決められる。
既定は「透明 + 枠線なし」で、ホーム画面のアイコンと同じ見え方になる。

**ホーム画面アプリのアイコンサイズ設定やラベル表示の設定は、外から読む手段がない。**
One UI も Pixel ランチャーも、その設定はランチャー自身の内部にあって公開されていないし、
`Settings` にも出てこない。`ActivityManager.getLauncherLargeIconSize()` は端末の標準値
(`app_icon_size` = 48dp) を返すだけで、ランチャーが実際に描く大きさとは別物。
なので自動で合わせるのはあきらめて、ショートカットごとに選べるようにしてある。

| 項目 | 選択肢 |
| --- | --- |
| アイコンの大きさ | 自動 (ウィジェットいっぱい) / 40 / 44 / 48 / 52 / **56 (既定)** / 64 / 72 dp |
| アプリ名の表示 | 自動 (入るときだけ) / 常に表示 / 表示しない |

既定を 56dp にしてあるのは、端末の標準値は 48dp でもランチャーは実際にはもう少し大きく描く
ことが多いため (Pixel ランチャーの実測でおよそ 57dp)。隣のアイコンと見比べて合わせてほしい。

「開くリンク」を入れるとディープリンクになる。例えば YouTube を選んで
`https://www.youtube.com/feed/subscriptions` を入れると、そのアプリで URL を開こうとする。
そのアプリで開けない URL だった場合は端末の既定のアプリに任せ、URL が無効なら普通にアプリを起動する。
リンクをアプリ内で処理するか外部ブラウザに渡すかは、最終的に対象アプリ側の判断になる。

アプリ一覧の取得にはマニフェストの `<queries>` に MAIN + LAUNCHER を書いてある。
制限付きの `QUERY_ALL_PACKAGES` は使っていない。

## セットアップ

1. APK をビルドしてインストールする。

   ```bash
   ./gradlew :app:assembleDebug
   ```

   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

2. アプリを開き、各機能の状態 (利用可能 / 権限不足 / 非対応) を確認する。

3. USB デバッグを使うなら、表示されているコマンドを PC で一度だけ実行する。

   ```bash
   adb shell pm grant net.shino3.qsmultitools android.permission.WRITE_SECURE_SETTINGS
   ```

   この権限はアプリを消すまで残る。USB デバッグを OFF にしても権限は残るので、
   次にタイルをタップすれば ON に戻せる。

4. 画面タイムアウトを使うなら「許可画面を開く」から「システム設定の変更」を許可する。
   adb でやるなら `adb shell appops set net.shino3.qsmultitools WRITE_SETTINGS allow` でもよい。

5. セットアップ画面下部の「タイルを追加」ボタン、またはクイック設定パネルの編集画面から
   タイルをパネルに置く。ウィジェットも同じ画面の「ウィジェットを追加」から置ける
   (ホーム画面アプリが追加リクエストに対応していない場合は、ウィジェット一覧から手動で追加する)。

## 実装メモ

設計判断とその根拠は [docs/DESIGN.md](docs/DESIGN.md) に置いた。

- Kotlin + フレームワーク API のみ。依存ライブラリはゼロ (AndroidX も Compose も入れていない)
- `minSdk 34` / `targetSdk 36` / `compileSdk 37`
- タイルは通常モード (`ACTIVE_TILE` を宣言しない)。バインドされるのはパネル表示中だけで常駐しない
- 設定書き込みは必ず読み戻して反映を確認する。OEM 側で握りつぶされた場合はトーストで知らせる

## 動作確認

Android 15 (API 35) のエミュレータで確認済み。

- 3 タイルの登録・表示・サブタイトル更新
- 権限なしでのタップ → セットアップ画面へ遷移、クラッシュなし
- 画面タイムアウトの巡回 (2分 → 10分 → 30分 → 30秒 → …)
- アラームタイル → 時計アプリのアラーム一覧が開く
- `requestAddTileService` によるタイル追加ダイアログ
- 「許可画面を開く」→ システムの「システム設定の変更」画面
- `requestPinAppWidget` によるウィジェット追加ダイアログ、および非対応ランチャーでの案内トースト
- ホーム画面上のウィジェット表示 (`次のアラーム / 8:30 AM / 明日`)、タップで時計アプリが開く
- リサイズ追従: 2x1 (233x120dp) → 大サイズ (605x393dp) で文字が拡大し、はみ出しなし
- 高さを詰めたときの行の間引き: 52dp で見出しが消え、42dp で時刻だけになる
- 背景テーマの切り替え (システム → ダーク → 透明) が設置済みウィジェットに即座に反映される
- 枠線 3dp が透明テーマで輪郭として描かれる
- ショートカット: 設定画面のアプリ一覧・絞り込み、YouTube を選んでアイコンとラベルが出ること、
  タップで YouTube が開くこと
- ショートカットのアイコン追従 (自動時): 108x120dp で 77dp、357x393dp で 160dp (上限) に拡大
- アイコンサイズ指定: 48dp / 56dp / 72dp を選ぶと実測でその通りに描かれること
- 「アプリ名の表示: 表示しない」でラベルが消えること
- ディープリンク: `setPackage` 付きの ACTION_VIEW が対象アプリに届くこと
  (ログ上で起動元 uid が YouTube であることを確認。その先どう扱うかはアプリ側の判断)
- edge-to-edge でアプリ画面の先頭が隠れていた不具合の修正
- 時計アプリでアラームを ON にすると `ACTION_NEXT_ALARM_CLOCK_CHANGED` を受けて
  ウィジェットが描き直される (`dumpsys appwidget` の RemoteViews が差し替わることを確認)

USB デバッグの ON/OFF そのものは、切り替えると adb 接続が切れてしまうためエミュレータでは
実行していない。実機で最初に確認すること。
